# 探索とPBRの実装

## 地形と歩行

探索用の地形はXZ座標から標高を決定します。CPUは8192m四方のタイルをカメラ周囲に9×9枚並べ、近いタイルを四分割して最小128mにします。各タイルは32×32区画なので、足元の地形は4m間隔です。128mの更新境界を越えると表示範囲を更新し、既存のタイルはGPUバッファを再利用します。解像度差で生じる境界の隙間はタイルの側面で覆います。[地形の生成と更新](../src/world.cpp)

`WASD` は水平入力で、歩く速度は4.2m/s、`Shift` で8.4m/sです。歩行時は描画と同じ三角形を補間して足元の高さを求め、カメラを地面から1.68mに置きます。小刻みに移動先を調べ、急斜面、木の幹、水深40cmを超える下りでは進行を止めます。深みに立つ座標から開始したり、飛行から歩行へ切り替えたりした場合は、近くの浅瀬に移ります。`G` で飛行に切り替えられます。探索座標の範囲はX・Zとも±500kmです。

## 草木と影

針葉樹は太さと曲がりを変えた幹・枝に、透明度付きの針葉を立体的に重ねます。2種類の樹形を使い、遠くでは枝数を減らします。細かな針葉がミップで消えないよう、画面上で小さくなるにつれてアルファのしきい値を下げます。木、シダ、岩は世界座標で配置を再現し、インスタンシングで描きます。[植生の生成](../src/world.cpp) · [素材の出典](../assets/world/credits.md)

草は地形タイルと同じ三角形の高さを、カメラ周囲の768m四方にキャッシュします。コンピュートシェーダーは、道・斜面・水深・水分・視野を使って草の根元を選びます。距離に応じて葉の枚数を12枚、6枚、4枚に変え、最遠310mまで間接インスタンス描画します。距離の境界では、世界座標から決まる乱数で密度を滑らかに変えます。カメラが止まっていれば配置バッファを再利用し、風は頂点だけを動かします。密度と地表の色には同じ水分分布を使っています。[草のシェーダー](../shaders/grass.hlsl) · [描画と距離設定](../src/grass.cpp) · [GDCの草原描画講演](https://gdcvault.com/play/1027033/)

草木は風向・風速で揺れ、雨で葉と樹皮の色・粗さが変わります。日中は384m四方・2048²の近距離シャドウマップに幹、針葉、シダ、近くの草と岩を描きます。針葉などの透過部分は、G-bufferと影の両方で同じアルファ判定を使います。葉の裏に回る光は合成で近似します。[植生の材質](../shaders/mesh.hlsl)

## 谷の稜線と遠景

USGSの標高データを縮尺と向きに合わせて加工し、谷の奥の地形へ滑らかに重ねます。稜線では地形LODを細かく保ち、岩肌の模様をXYZの3方向から投影します。標高と斜度で樹林、露岩、雪の色を変えます。谷の奥には薄い霞を積分し、手前の草や川と奥の山の距離を表します。[地形データの出典と加工](../assets/world/credits.md) · [地形の照明](../shaders/scene.hlsl)

探索カメラの深度は32bit浮動小数点のreversed-Zを使い、近面を0.15mにしています。草木の細い輪郭は合成後に輝度差を使って一度濾過します。[深度とG-buffer](../shaders/common.hlsli) · [輪郭の濾過](../shaders/scene.hlsl) · [参考のFXAA資料](https://developer.download.nvidia.com/assets/gamedev/files/sdk/11/FXAA_WhitePaper.pdf)

## 川と河原

河道の中心と幅、1kmあたり2.2mの勾配をC++とHLSLで共有します。地形をその高さまで掘り、河床や浅瀬の深さを場所ごとに変えます。岸には砂利と岩を置き、小さな凹凸を入れます。水面は視線と川の高さの交点から求め、地形や草木が手前にある画素は深度で隠します。霧と雨も同じ水面の深度を参照します。[河道の定義](../shaders/river_profile.hlsli) · [河床の生成](../src/world.cpp)

岸から離れるほど速く流れる法線の波を使います。斜めから見るほどフレネル反射が強くなり、浅瀬では屈折した川底が透けます。深いところでは、水中を通る距離に応じて光が吸収・散乱します。空と雲は背景のバッファから、木や対岸は画面内の深度をたどって反射させます。画面外の方向は天空光で補います。水面の直射光にも雲影と近距離の影を掛けます。[水面のシェーダー](../shaders/river_water.hlsli)

## 時刻と天候

時計は太陽時です。緯度40°N・太陽赤緯16°の固定条件で、時角から太陽高度と方位を計算します。太陽の方向を空、雲、地形、モデルの直接光、影に共有します。夜は月と星を描き、地表には月明かりの近似を足します。時刻と天候はそれぞれ操作できます。

探索を普通に起動すると15:42から始まり、実時間12分で1日が進みます。`--time 18.5 --day-seconds 0` は18:30に固定します。`--time` は0以上24未満の十進数の時刻です。`--day-seconds 120` で1日を120秒にできます。ヘッドレスキャプチャは既定で時刻を固定します。

## glTFモデルのPBR

`--model` は静的な `.glb` と `.gltf` の三角形メッシュを読み、開始視点の約9m前でバウンディングボックスの底を地面に合わせます。glTFのノード変換、頂点色、UV0・UV1、PNG・JPEGの埋め込み画像と外部画像を扱います。モデルの寸法は `--model-scale` で調整できます。

ベースカラーと発光はsRGBで読み、金属度・粗さ・法線・AOは線形で扱います。金属度はB、粗さはGから取り、G-bufferの金属度を使ってGGXの反射と拡散光の割合を変えます。AOは環境光へ掛けます。環境反射は半球の近似です。透明度モードは `OPAQUE` と `MASK` に対応します。透過ブレンド、スキニング、モーフ、インポートしたモデルの当たり判定は未実装です。[glTFの仕様](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html) · [モデルローダー](../src/model.cpp) · [材質のHLSL](../shaders/mesh.hlsl)

glTFの構文解析には同梱のcgltf v1.15を使い、画像はWindows Imaging Componentで展開します。[cgltfのMITライセンス](../third_party/cgltf/LICENSE)

## 再現コマンド

```powershell
# 同じ歩行処理で地形タイルの境界をまたぐ
.\out\vs\Release\CirrusEngine.exe --headless --no-ui --camera-path walk --spawn 10 123 --frames 90 --fixed-dt 0.1 --capture captures/walk.png

# 元の84km四方の地形を越えた地点から探索
.\out\vs\Release\CirrusEngine.exe --camera walk --spawn 250000 180000

# 対岸から川と樹皮を見る。角度はヨーとピッチの順で度数指定
.\out\vs\Release\CirrusEngine.exe --camera walk --spawn 53 25 --look -25 -7 --time 16.4

# 既存の雲・天候と、新しい歩行・時刻・材質をまとめて検証
.\scripts\validate.ps1
```

キャプチャの診断JSONにはカメラ座標、地面高との差、タイル数、草木と川岸の岩のインスタンス数、太陽時、モデルの描画単位数が入ります。`grass_lods` は、GPUが選んだ草の根元の数を近い順に記録します。`F3` の一覧または `--debug-view 31` で手前に水面がある画素を白で確認できます。金属度は `29`、粗さは `21`、近距離の影は `30` です。
