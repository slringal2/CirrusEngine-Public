# Cloud texture sources

- `scales.png` derives cloud shapes from Jeff Caplan and Lin Chambers's cirrocumulus photographs in the [NASA Langley S'COOL gallery](https://scool.larc.nasa.gov/GLOBE/cirrocumulus.html). The clear-sky luminance was estimated locally. The cloud density patches were assembled into a periodic 4096 x 4096 map with fine procedural detail.
- `cirrus.png` derives density from the Cirrus photograph in the [National Weather Service Louisville cloud guide](https://www.weather.gov/lmk/cloud_classification).
- `veil.png` was authored procedurally for CirrusEngine.

The texture PNGs contain density, thickness and height data derived for engine use. See the [NASA media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) and the [NWS disclaimer](https://www.weather.gov/disclaimer) for the original material.
